# 0.50: per-kind dictionaries (P3) and the criterion-6 bench gate

Measured in the 0.50 development sandbox (Linux x86_64, Python 3.13.18,
`backports.zstd`), single-threaded, seed 37, 40 synthetic runs of 24 steps
(`scripts/bench/run_bench.py --runs 40`). These numbers are from one machine
and are not the CI gate: the gate reruns both sides on the CI runner.

## Criterion 6: the bench against 0.40.0

`scripts/bench/run_bench.py --library <v0.40.0 checkout>` benches the 0.40.0
tag's `opentine/` with the same interpreter, dependencies and bench script;
`scripts/bench/gate.py` compares the two reports. The bench workflow runs both
on the same runner in the same job (hardware-pinned, relative) and fails when
the stored bytes of `gc`, `gc_v3`, `wire` or `bundle` grow by more than 5%.

| gc | 1,789,883 | 1,789,883 | 1.000 | 1.331 | pass |
| gc_v3 | 502,342 | 502,342 | 1.000 | 0.960 | pass |
| wire | 3,673,401 | 3,673,401 | 1.000 | 0.996 | pass |

| zstd19_per_object | 3,022,229 | 3,022,229 | 1.000 | 0.957 | reported |

Sizes are identical to 0.40.0. Throughput is reported, not gated: it varies by
more than 5% between two runs of the same code on one machine (the bundle and
gc speed ratios above are single runs of a few hundred milliseconds), so a 5%
speed gate would fail at random. Whether the bundle write slowed down is not
settled by these numbers; it needs repeated runs on the pinned runner.

## Dictionaries

`gc_dicts` is `tine gc --dictionaries` on the same repository: packs plus the
`dicts/` they need. gc trains a dictionary per kind and keeps it only when it
saves more than its own size; on this corpus none does, so no dictionary is
kept and the size equals `gc_v3`.

Forcing a dictionary of each size on every trained kind (blob, event) shows
why, total bytes = packs + dictionaries:

| dictionary size | packs | dictionaries | total |
|---:|---:|---:|---:|
| none | 502,342 | 0 | 502,342 |
| 8 KiB | 499,582 | 24,799 | 524,381 |
| 16 KiB | 491,826 | 49,375 | 541,201 |
| 32 KiB | 481,275 | 98,527 | 579,802 |
| 64 KiB | 485,709 | 131,222 | 616,931 |
| 110 KiB (zstd default) | 474,566 | 225,430 | 699,996 |

A dictionary saves up to 5.5% of the packs but costs more than it saves:
16 MiB kind-grouped blocks at zstd-19 already find the repetition a dictionary
would supply, as the 0.37 bench found for long mode. Dictionaries pay where
blocks are small relative to the corpus (many small packs of similar objects
sharing one dictionary); the reuse of the last dictionary per kind by a small
gc is for that case. They stay opt-in and off by default.
